# Generate a Short

1. Open **Setup** — ElevenLabs, Kling, and ffmpeg must all be Ready (add YouTube too if you want one-click publish).
2. Go to **Create**, enter a topic, click **Generate short**.
3. Stay on the episode page while it runs:
   - Script (5 story beats)
   - ElevenLabs voiceover
   - Scenes 1–5 (Kling image → motion)
   - Final video with captions
4. When status is **Ready**, preview the Short, edit the title or caption, then download or **Publish to YouTube**.

## What you get

A ~45–60s vertical Short with:

- Faceless narrator (ElevenLabs)
- Five Kling scenes matched to the story
- Burned-in captions
