#  Front-End Developer & Designer Portfolio Codepen Showcase GSAP ScrollTrigger

A Pen created on CodePen.

Original URL: [https://codepen.io/Margarita-the-solid/pen/ZYLoLBe](https://codepen.io/Margarita-the-solid/pen/ZYLoLBe).

An exploration of advanced DOM-manipulation and high-performance motion design. This interactive brutalist portfolio showcases several cutting-edge front-end mechanics:

Dynamic Theme Recoloring: GSAP ScrollTrigger seamlessly transitions CSS variables for background and accent colors based on scroll position.
Elastic Cursor Physics: A custom JS cursor that calculates velocity vectors to dynamically squish and stretch as it tracks mouse movement.
Lazy-loaded Embeds: A high-performance interactive modal that dynamically loads heavy CodePen iframes only when opened, keeping the initial page weight extremely light.
