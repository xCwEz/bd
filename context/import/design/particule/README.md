# Particulate — Shatter an Image, Harvest a Palette

A Pen created on CodePen.

Original URL: [https://codepen.io/fyildiz1974/pen/ByzvNEo](https://codepen.io/fyildiz1974/pen/ByzvNEo).

Drop any image and watch it explode into thousands of physics-driven particles, each carrying its original pixel color. Blow them apart, pull them together with a magnet, or freeze the chaos mid-air. Behind the spectacle, a Median Cut algorithm extracts the dominant color palette from your image — sorted by luminance, shown with percentages. Three interaction modes: Blow (scatter particles outward), Gather (magnetic pull), and Freeze (pause physics). Press Space to detonate everything. Press R to reassemble. Every piece finds its way home. Built for #CodePenChallenge: Color Palettes — because the best palette is already hiding inside your favorite photo. You just need to break it open.
